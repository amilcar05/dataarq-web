Servicios

Catálogo de servicios

Seis líneas de trabajo, cada una acotada a un momento distinto del ciclo de vida del dato.

CódigoServicioQué incluye
DB–01 Modelado de datos Diagramas entidad–relación, diccionario de datos y diseño de esquemas normalizados.
DB–02 Arquitectura de bases de datos Diseño cliente/servidor y distribuido según el volumen de usuarios y el tipo de aplicación.
DB–03 Auditoría y optimización Detección de problemas de normalización, claves e índices en bases de datos existentes.
DB–04 Ingeniería inversa y reingeniería Reconstrucción del modelo de datos de sistemas legados y propuesta de un esquema moderno.
DB–05 Migración y modernización Paso de arquitecturas centralizadas a esquemas cliente/servidor o distribuidos, sin perder datos.
DB–06 Gestión de configuración de esquemas Control de versiones de scripts y cambios de base de datos, con procedimiento de rollback.

Metodología

Cómo trabajamos, paso a paso

  1. 01

    Relevamiento

    Entrevistas con el equipo del cliente y análisis de sus requisitos de información.

  2. 02

    Diseño / diagnóstico

    Modelado de datos para un sistema nuevo, o ingeniería inversa del esquema actual si ya existe uno.

  3. 03

    Validación

    Revisión técnica formal del modelo propuesto junto al cliente, antes de tocar producción.

  4. 04

    Implementación

    Scripts de creación o migración, carga y validación de los datos.

  5. 05

    Mantenimiento

    Gestión de configuración de esquemas para que los cambios futuros queden documentados y sean reversibles.
